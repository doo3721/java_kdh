## 1교시: 복습, 배열 접근시 발생할 수 있는 예외

- NullPointerException
  - 참조 변수가 null인 상태(아직 주소값을 가리키지 않은 상태)에서 배열 요소에 접근하려고 index를 지정할 시 발생

    ```java
    int[] arr = null;
    // arr[0] = 10; // NullPointerException 발생
    ```

- ArrayIndexOutofBoundsException
  - 배열 인덱스의 유효 범위인 ‘0’부터 ‘length - 1’

## 2-5교시: 메소드 (Method)

- 메소드 (Method)
  - 특정 기능을 수행하기 위한 관련된 코드들을 하나의 블록을 묶어 놓은 것
  - 필요할 때마다 호출, 여러번 재사용 가능
- 메소드의 의의와 장점
  - 코드의 재사용성 증대
  - 코드의 중복 제거
  - 유지보수성 향상
  - 가독성 및 구조화
- 메소드 선언

    ```java
    [접근제어자] 반환타입 메소드명(매개변수타입 매개변수명, ...) {
      // 실행할 코드 블록
      return 반환값; // 반환타입이 void가 아닐 때만 사용
    }
    ```

  - 접근제어자: 메소드를 호출할 수 있는 범위를 지정
    - public: 클래스 내부,외부 상관없이 호출 가능
    - private: 같은 클래스 내부에서만 호출 가능
    - protected: 동일한 패키지 내의 클래스들, 상속 관계에 있는 자식 클래스에서 호출 가능
    - default (기본값): 동일한 패키지 내애 있는 클래스들에서만 호출 가능
  - 반환타입: 메소드가 실행을 마치고 반환할 데이터의 타입
    - int, double 등의 기본타입
    - String 등의 클래스 객체
    - 반환값이 없을 경우 void로 명시
  - 메소드명: 메소드의 이름
  - 매개변수 (Parameter): 메소드 호출 시 외부에서 전달받는 값을 저장하는 변수
    - 필요없을 경우 생략 가능
- 메소드 호출
  - 선언된 메소드를 실행하기 위해 메소드명과 필요한 인자를 전달하여 호출

    ```java
    메소드명(인자1, 인자2, ...); // 반환값이 없거나 반환값을 사용하지 않을 때
    변수타입 변수명 = 메소드명(인자1, 인자2, ...); // 반환값을 변수에 저장할 때
    ```

- main 메소드
  - 자바 프로그램의 시작점(Entry Point) 역할을 하는 특수 메소드
  - JVM은 프로그램을 실행할 때 main 메소드를 찾아 실행
  - 전통적인 main 메소드 선언

      ```java
      public class HelloWorld {
        public static void main(String[] args) {
          // 프로그램 실행 시 시작할 코드
        }
      }
      ```

    - public: JVM이 어디서나 main 메소드에 접근하여 실행할 수 있어야 함
    - static: JVM이 클래스의 인스턴스 객체를 메모리에 생성하지 않고도 클래스 이름으로 바로 메소드를 호출하여 실행
    - void: main 메소드의 실행이 끝나면 프로그램 자체가 종료되므로, 호출한 JVM에게 돌려줄 반환값이 없다는 것을 의미
    - String[] args: 프로그램 실행시 터미널 등 외부에서 전달하는 문자열 매개변수들을 배열 형태로 전달받음
  - Java 21 이후의 새로운 main 메소드 문법

      ```java
      // java 21부터 적용되는 간략화 문법
      void main() {
        System.out.println("New Hello World");
      }
      ```

    - Java 21 부터는 간결하게 main 메소드를 작성할 수 있도록 새로운 문법이 제공
    - Implicitly Declared Classes and Instance Main Methods
    - 암묵적으로 선언된 클래스 (Implicitly Declared Classes)
      - 클래스 선언을 아예 생략, 멤버 메소드만 작성하여 선언
      - 컴파일러가 소스코드 파일명을 클래스명으로 인식, 암묵적인 클래스를 자동 생성
      - 단, 외부 다른 클래스에서 import하여 사용할 수 없음 → 단독 실행용 클래스에서만 사용
      - IntelliJ 같은 IDE의 프로젝트 탐색기에서는 완전한 자바 클래스 구조로 취급되지 않음, 파일명 뒤에 ‘.java’ 확장자가 그대로 표시
    - 인스턴스 메인 메소드 (Instance Main Methods)
      - public, static 키워드를 생략, ‘void main()’ 형식으로만 간결하게 선언
      - 명령형 매개변수가 필요 없을 경우 생략 가능 (args 생략)
      - JVM이 클래스를 생성할 때 내부적으로 객체 인스턴스를 자동으로 먼저 생성한 후 main 메소드를 호출
      - 이에 따라 클래스 내부의 다른 인스턴스 메소드를 호출할 때, 예전처럼 클래스 자신의 객체를 new 연산자로 직접 생성하지 않고도 곧바로 메소드명만 써서 간편하게 호출 가
- 명령형 매개변수
  - 프로그램을 실행할 때 외부에서 값을 전달받아 사용할 수 있는 매개변수
  - main 메소드의 매개변수 ‘String[] args’ 배열을 통해 전달됨
  - 터미널이나 콘솔 창에서 프로그램을 실행 할 때 클래스명 뒤에 공백을 기준으로 전달인자를 나열
  - 전달받은 데이터는 모두 String 타입으로 처리, 수로 사용시 형변환이 필요
- 메소드 오버로딩 (Overloading)
  - 동일한 이름을 가진 메소드를 한 클래스 내에 여러 개 정의하는 것
  - 원래 클래스 내에서 메소드 이름을 중복될 수 없다

    → 매개변수의 개수나 타입이 서로 다르면 동일한 메소드를 중복해서 정의가능

    - 클래스 내의 메소드 이름이 같으면 컴파일러가 어떤 메소드를 호출해야 할 지 알 수 없음
    - 하지만 메소드의 매개변수가 다르다면 이름이 같더라도 식별 가능
  - 메소드를 사용할 때 데이터 타입에 관계없이 일관된 하나의 이름만 사용할 수 있어 개발편의성을 높일 수 있음
- 가변 인자 (varargs, Variable Arguments)
  - 메소드를 호출 할 때 매개변수의 개수를 동적으로 지정할 수 있게 해주는 기능
  - 메소드 정의 시 타입 뒤에 세 개의 마침표(…)를 붙여 선언
  - 특징
    - 내부적으로 배열 처리: 가변 인자로 전달받은 값들은 메소드 내부에서 해당 타입의 배열로 자동 변환
    - 가변 인자의 위치 규칙: 가변 인자는 메소드의 매개변수 목록에서 반드시 가장 마지막에 위치. 마지막이 아닐 경우 컴파일 에러
    - 단일 가변 인자 규칙: 하나의 메소드에는 단 하나의 가변 인자만 선언가능
