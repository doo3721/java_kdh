## 1~3교시: 복습

## 4~5교시: 테이블 수정, DML

- 테이블 수정 (ALTER TABLE)
    - 생성된 테이블의 구조를 변경
    - 기존 테이블에 새로운 컬럼을 추가하거나, 기존 컬럼의 데이터 타입 및 제약조건을 수정하고, 더 이상 필요없는 컬럼을 제거하는 구조 조작 작업을 수행
    - 컬럼 추가

        ```sql
        ALTER TABLE 테이블명 ADD 컬럼명 데이터타입 [제약조건];
        ```

    - 컬럼 수정

        ```sql
        ALTER TABLE 테이블명 MODIFY 컬럼명 데이터타입 [제약조건];
        ```

    - 컬럼 삭제

        ```sql
        ALTER TABLE 테이블명 DROP COLUMN 컬럼명;
        ```

- 테이블 삭제 (DROP TABLE)
    - 데이터베이스 내에 더 이상 사용하지 않는 테이블을 영구적으로 제거
    - 삭제 시 테이블 구조뿐만 아니라 내부에 저장되어 있던 모든 데이터가 함께 소멸되므로 실행 시 주의

        ```sql
        DROP TABLE 테이블명;
        ```

- 테이블 초기화 (TRUNCATE TABLE)
    - 테이블의 구조는 남겨둔 채 내부의 모든 데이터 행을 삭제하여 테이블 생성 초기 상태로 리셋
    - DELETE 명령어와 달리 로그를 남기지 않아 롤백이 불가능
    - 대용량 데이터를 빠르고 효율적으로 비우고자 할 떄 주로 활용

        ```sql
        TRUNCATE TABLE 테이블명;
        ```

- DML (Data Manipulation Language)
    - 생성된 테이블에 데이터를 저장하고, 수정하며, 삭제하기 위해 사용하는 명령어 집합
    - INSERT, SELECT, UPDATE, DELETE 가 존재
- 데이터 삽입 (INSERT)
    - 정의된 데이터 구조에 맞추어 새로운 레코드 행을 추가
    - 모든 컬럼의 값을 순서대로 명시하여 한 행을 삽입하거나, 특정 필수 컬럼에만 값을 입력하여 저장 영역을 생성
    - 하나의 쿼리로 다량의 레코드를 일괄 삽입하는 다중 행 삽입 가능

    ```sql
    -- 모든 컬럼 값 삽입 (컬럼명 생략)
    INSERT INTO 테이블명 VALUES (값1, 값2, ...);
        
    -- 특정 컬럼 값 삽입 (선택적 컬럼 입력)
    INSERT INTO 테이블명 (컬럼1, 컬럼2) VALUES (값1, 값2);
    
    -- 다중 행 삽입
    INSERT INTO 테이블명 (컬럼1, 컬럼2) VALUES (값1, 값2), (값3, 값4), (값5, 값6);
    ```

- 데이터 조회 (SELECT)
    - 데이터베이스에서 원하는 조건의 데이터를 조회하는 명령어
    - 데이터베이스 내 특정 테이블에 보관된 레코드를 조회하여 사용자에게 반환
    - 필터링 조건을 지정하지 않을 경우 테이블에 적재된 모든 데이터 행을 읽어옴
    - 데이터의 전체적인 상태나 컬럼 구성을 확인할 때 주로 사용

    ```sql
    -- 특정 컬럼 조회
    SELECT 컬럼명1, 컬럼명2 FROM 테이블명;
    
    -- 전체 컬럼 조회
    SELECT * FROM 테이블명;
    
    -- 별칭(Alias) 사용 시 (AS 생략 가능)
    SELECT 컬럼명1, 컬럼명2 [AS] 별칭 FROM 테이블명;
    
    -- 중복 제거 조회
    SELECT DISTINCT 컬럼명 FROM 테이블명;
    ```

- 데이터 수정 (UPDATE)
    - 테이블 내에 이미 저장되어 있는 특정 행의 데이터를 조건에 맞추어 원하는 값으로 갱신
    - 특정 조건에 부합하는 레코드만 필터링하여 안전하게 변경하기 위해 WHERE 절이 필수
        - 생략 시 테이블 전체 행의 데이터가 일괄 갱신되는 결과를 초래할 수 있으므로 주의
    - 안전한 수정을 위해 SELECT를 먼저 수행해서 수정할 레코드만 조회되는지 확인 후 수정을 권장

    ```sql
    UPDATE 테이블명 SET 컬럼1 = 값1, 컬럼2 = 값2 WHERE 조건;
    ```

- 데이터 삭제 (DELETE)
    - 테이블 내부에서 더 이상 불필요해진 데이터를 행 단위로 영구 삭제
    - 조건식을 지정하는 WHERE 절을 활용하여 특정 타겟 레코드만 제거
        - 생략 시 테이블 내의 전체 데이터가 모두 지워질 수도 있으니 주의
    - 안전한 수정을 위해 SELECT 수행 후 삭제할 레코드만 조회되는지 확인 후 삭제를 권장

    ```sql
    DELETE FROM 테이블명 WHERE 조건;
    ```


## 6교시: SELECT 문 기초 (WHERE, ORDER BY, LIMIT)

- WHERE
    - 테이블 내 전체 데이터 중 원하는 조건에 부합하는 레코드만 선별하여 조회
    - 다양한 비교 연산자와 논리 연산자를 결합하여 복합적인 필터 조건을 정의할 수 있으며, 패턴 매칭 및 범위, 다중 목록 검색 연산자를 활용한 유연한 데이터 필터링도 지원

    ```sql
    SELECT 컬럼명 FROM 테이블명 WHERE 조건;
    ```

    - 주요 연산자 종류
        - 비교 연산자: =, <>, !=, >, <, >=, <=
        - 논리 연산자: AND, OR, NOT
        - 패턴 매칭 연산자: LIKE (%는 길이 제한 없는 문자열, _는 개당 문자 1개 매칭)
        - 기타 조건 연산자: BETWEEN A AND B, IN (값1, 값2, …), IS NULL / IS NOT NULL
- ORDER BY
    - 검색된 결과를 지정한 컬럼 기준에 따라 정렬
    - 기본적으로 오름차순으로 정렬, 내림차순으로도 지정 가능
    - 정렬 기준 컬럼을 여러 개 나열하여 1차 정렬 후 동일한 값에 대해 2차 정렬을 수행할 수도 있음

    ```sql
    SELECT 컬럼명 FROM 테이블명 ORDER BY 컬럼명 [ASC|DESC];
    ```

    - 정렬 방식 구분
        - 오름차순 (ASC): 숫자(작은 값부터), 문자(사전 순), 날짜(과거부터 최신) 순서로 정렬
        - 내림차순 (DESC): 숫자(큰 값부터), 문자(사전 역순), 날짜(최신부터 과거) 순서로 정렬
- LIMIT
    - 쿼리 실행 결과로 반환되는 레코드의 최대 개수를 제한하여 출력
    - 불필요하게 많은 데이터가 한 번에 조회되는 현상을 방지하여 시스템 부하를 낮춤
    - 시작 위치를 지정하는 오프셋 설정과 결합하여 게시판의 페이징 처리를 구현할 때 활용

    ```sql
    SELECT 컬럼명 FROM 테이블명 LIMIT [시작위치,] 개수;
    ```

    - 주요 설정 방식
        - 단일 값 지정: LIMIT 개수 형식으로 처음부터 지정한 개수만큼 반환
        - 오프셋 지정: LIMIT 시작위치, 개수 형식으로 시작위치(0부터 시작)에서 지정한 개수만큼 반환
