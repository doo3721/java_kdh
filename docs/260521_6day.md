## 4-6교시: 반복문

- while 문
    - 지정한 조건식이 참 일 경우 조건이 거짓이 될 때까지 해당 블록을 반복하여 수행
    - 반복 횟수는 정해져 있지 않지만, 특정 조건이 만족할 때까지 루프를 유지
- do-while 문
    - 일단 블록의 내부 구문을 최초 1회 먼저 실행 후, 조건식을 검사하여 조건이 참 일 동안 루프를 지속
    - 조건식의 만족 여부에 상관없이 최소 1번의 실행을 보장
- for 문
    - 초기화, 조건식, 증감식을 사전에 지정할 수 있는 반복문
    - 반복 횟수가 명확할 때 주로 사용
    - 실행 순서
        - 초기화 → 조건식 → 참 일 경우 구문 실행 → 증감식 → 조건식 → 참 일 경우 구문 실행 → 증감식 → … (반복) → 조건식 → 거짓 → for 문 종료
        - 증감식은 전위연산, 후위연산 상관없이 처음 구문 실행 후 증감식이 연산된다.
