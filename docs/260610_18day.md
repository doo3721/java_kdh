## 2~3교시: String, StringBuffer, StringBuilder, 래퍼 클래스

- 가변 문자열 클래스: StringBuffer와 StringBuilder
    - 문자열의 잦은 편집이 일어나는 프로그램에서 힙 공간 낭비 방지를 위한 가변 객체 클래스
    - StringBuffer
        - 멀티스레드 환경에서 안전한 동기화(Thread-safe) 처리
    - StringBuilder
        - 동기화 처리가 생략된 싱글스레드 환경 최적화 클래스
        - 웹 백엔드의 로컬 변수 조작 등에서 속도 최적화를 위해 사용
- String 주요 메소드
    - length(): 문자열 총 길이 반환
    - charAt(int index): 특정 index 문자 반환
    - subString(int begin, int end): 시작부터 끝 직전까지 문자열 반환
    - equals(Object obj): 내용 일치 여부 반환
    - indexOf(String str): 찾는 문자(열)의 시작 index 반환
    - replace(CharSequence target, CharSequence replacement): 치환된 새 문자열 반환
    - split(String regex): 구분 기호를 기준으로 분리된 문자열 배열 반환
- StringBuffer 주요 메소드
    - append(String str): 끝 부분에 문자열 추가
    - insert(int offset, String str): 특정 위치부터 문자열 삽입
    - delete(int start, int end): 특정 범위 문자 제거
    - reverse(): 문자열 반전
    - toString(): 최종 결과물 String 객체 반환
- 래퍼 클래스 (Wrapper Class)
    - 기본 자료형(Primitive Type) 데이터를 객체로서 다루어야 할 때 사용
        - Object[]에 기본 자료형을 저장하거나 Integer.parseInt()같은 객체 지원 메소드 등
    - 특징
        - 기본 타입 매핑: 각 기본 타입에 일대일 매핑되는 래퍼 클래스가 제공
        - 오토 박싱 (Auto-boxing) 및 오토 언박싱 (Auto-unboxing): 기본 타입과 래퍼 객체 타입이 필요에 따라 자동으로 상호 변환되도록 지원하여 편의성이 높음
        - 데이터 파싱 메소드: 외부 문자열로 넘어온 데이터를 각 기본 타입 데이터로 파싱하여 리턴하는 static 메소드들을 제공
            - Integer.parseInt(String str) 등

## 4교시: Math, Scanner

- Math 클래스
    - 절대값, 반올림, 올림, 내림, 거듭제곱, 난수, 생성 등 수학 연산과 계산이 필요할 때 사용
    - 특징
        - 정적 멤버 구조: 모든 필드와 메소드가 static으로 선언되어 있어 별도의 인스턴스 생성 없이 클래스명으로 직접 호출
        - 메소드 오버로딩 적용: max, min, abs 등 주요 메소드들이 다양한 데이터 타입을 지원하도록 오버로딩 되어 있음
        - 인스턴스화 차단: 생성자가 private로 선언되어 있어 객체를 단독으로 생성할 수 없음
    - 주요 메소드
        - `int abs(int a)`: a의 절대값을 반환
        - `int max(int a, int b)`: a, b 두 정수 값 중 더 큰 값을 반환
        - `int min(int a, int b)`: a, b 두 정수 값 중 더 작은 값을 반환
        - `long round(double a)`: a의 소수점 첫째 자리에서 반올림한 정수형 값을 반환
        - `double ceil(double a)`: a의 소수점 이하를 올림한 값을 반환
        - `double floor(double a)`: a의 소수점 이하를 내림한 값을 반환
        - `double random()`: 0.0 이상 1.0 미만 범위의 난수(random double)를 생성하여 반환
        - `double pow(double a, double b)`: a의 b제곱한 거듭제곱 값을 반환
        - `double sqrt(double a)`: 양수 a의 제곱근 값을 반환
- Scanner 클래스
    - 콘솔 표준 입력(System.in)이나 파일 등으로부터 텍스트 데이터를 읽어서 원하는 타입으로 파싱하여 가져오기 위해 사용
    - 특징
        - 간편한 토큰 파싱: 공백이나 개행을 구분자로 삼아 문자열, 정수, 실수, 등 알맞은 타입의 데이터로 파싱하여 리턴
        - 리소스 누수 주의: 파일로부터 데이터를 읽을 경우 사용이 끝난 스트림 리소스를 해제하기 위해 반드시 close() 메소드로 닫아주어야 함
    - 주요 생성자
        - `Scanner(InputStream source)`: 표준 입력 등 지정한 입력 스트림으로부터 데이터를 읽는 Scanner 객체를 생성
        - `Scanner(String source)`: 지정한 문자열 데이터를 읽는 Scanner 객체를 생성
        - `Scanner(File source)`: 지정한 파일로부터 데이터를 읽는 Scanner 객체를 생성
    - 주요 메소드
        - `String next()`: 다음 공백 이전까지의 텍스트 단어를 문자열로 읽어서 반환
        - `String nextLine()`: 다음 개행 문자(엔터) 이전까지의 한 줄 전체 텍스트를 읽어서 반환
        - `int nextInt()`: 입력된 다음 토큰을 int형 정수로 파싱하여 반환
        - `double nextDouble()`: 입력된 다음 토큰을 double형 실수로 파싱하여 반환
        - `boolean hasNext()`: 읽어올 다음 토큰이 있는지 여부를 반환
    - 개행 오류 문제
        - next직후 nextLine을 사용하면 next에서 남아있던 개행이 nextLine으로 넘어가 강제로 문자열 입력이 넘어가는 문제
        - next 후 빈 nextLine을 호출하여 개행 제거 또는 문자열 입력을 nextLine으로 통일해야 함

## 5교시: Random, java.time 패키지

- Random 클래스
    - 정수, 실수, 논리값 등 다양한 형태의 무작위 난수를 획득하고자 할 때 사용
    - 특징
        - seed 기반 난수: 내부 시드 값을 활용하여 난수 테이블에서 값을 추출
            - 시드 값이 같으면 항상 동일한 순서의 난수를 얻을수 있음
            - Math.random()이나 Random() 생성자에 시드를 지정하지 않으면 시스템의 시간을 시드 값으로 사용
        - 풍부한 데이터 난수 제공: Math.random에 비해 특정 정수 범위(0~N 미만)를 구하는 nextInt(bound)나 무작위 논리값인 nextBoolean() 메소드를 제공하여 직관적이고 유연하게 활용 가능
    - 주요 생성자
        - `Random()`: 현재 시스템 시간(나노초)을 시드로 설정하여 무작위 난수를 발생하는 Random 객체를 생성
        - `Random(long seed)`: 지정한 값을 시드로 설정하여 무작위 난수를 발생하는 Random 객체를 생성 (seed가 같으면 항상 동일한 순서의 난수 생성)
    - 주요 메소드
        - `int nextInt()`: 모든 정수 범위(음수 포함)에서 무작위 int 정수 값을 반환
        - `int nextInt(int bound)`: 0 이상 bound 미만 범위에서 무작위 int 정수 값을 반환
        - `double nextDouble()`: 0.0 이상 1.0 미만 범위의 무작위 double 실수를 반환
        - `boolean nextBoolean()`: 무작위 boolean 값(true 또는 false)을 반환
- java.time 패키지
    - 자바 8부터 도입, 날짜와 시간을 효율적이고 안전하게 다룰 수 있는 현대적인 API를 제공
    - 과거에는 Date, Calender 클래스를 주로 사용했으나, 값의 변경이 자유로워 스레드에 안전하지 못하고 Month가 0부터 시작하는 등 설계 결함이 많음
    - 특징
        - 불변 객체 설계: java.time 패키지의 핵심 클래스들은 내부 값을 변경할 수 없는 불변 객체, 수정 시 새로운 객체를 반환하여 멀티스레드 환경에서 안전함
        - 명확하고 직관적인 표기법: Month 정보를 다룰 때 1월은 1, 12월은 12로 직관적으로 대응
        - 용도별 명확한 클래스 구분: 날짜만 관리할 때 LocalDate, 시간만 관리할 때는 LocalTime, 둘 모두 관리할 때는 LocalDateTime과 같이 목적에 적합한 클래스 선택
    - 주요 메소드
        - `LocalDate LocalDate.now()`: 현재 시스템의 날짜 정보를 가진 LocalDate 객체를 반환
        - `LocalDateTime LocalDateTime.now()`: 현재 시스템의 날짜와 시간 정보를 가진 LocalDateTime 객체를 반환
        - `LocalDate plusDays(long daysToAdd)`: 현재 날짜에 daysToAdd 일수만큼 더한 새로운 LocalDate 객체를 반환
        - `LocalDate minusDays(long daysToSubtract)`: 현재 날짜에 daysToSubtract 일수만큼 뺀 새로운 LocalDate 객체를 반환
        - `int getYear()` / `int getMonthValue()` / `int getDayOfMonth()`: 각각 객체로부터 연도, 월(1~12), 일(1~31) 정보를 정수로 추출하여 반환
        - `String format(DateTimeFormatter formatter)`: 지정한 포맷 규칙(DateTimeFormatter)에 맞추어 날짜 및 시간 데이터를 문자열로 출력하여 반환
            - DateTimeFormatter는 ofPattern("yyyy-MM-dd HH:mm:ss") 등의 정적 메서드를 이용해 원하는 포맷 형식을 정의하여 제공함
                - yyyy: 4자리 연도 (예: 2026)
                - yy: 2자리 연도 (예: 26)
                - MM: 2자리 월 (예: 06)
                - M: 1자리 또는 2자리 월 (예: 6, 12)
                - dd: 2자리 일 (예: 09)
                - d: 1자리 또는 2자리 일 (예: 9, 23)
                - HH: 24시간제 시 (00 ~ 23)
                - hh: 12시간제 시 (01 ~ 12)
                - mm: 2자리 분 (00 ~ 59)
                - ss: 2자리 초 (00 ~ 59)
                - a: 오전/오후 표시 (AM/PM)
                - E: 요일 (예: 월, 화, 수)

## 6교시: ArrayList

- ArrayList 클래스
    - 데이터의 개수가 유동적으로 늘어나거나 줄어드는 동적 목록(가변 리스트)을 안전하고 편리하게 관리하기 위해 사용함
    - 특징
        - 동적 배열 확장: 내부적으로 관리하는 배열 공간이 가득차면 자동으로 더 넓은 메모리 배열을 선언하고 데이터를 복사, 크기 제한 없이 저장 공간을 동적으로 다룸
        - 제네릭 (Generic) 적용: 꺽쇠 괄호(< >) 안에 저장할 데이터 타입을 지정, 잘못된 타입의 객체가 저장되는 것을 방지하고 타입 안정성을 확보
    - 주요 생성자
        - `ArrayList<E>()`: 초기 용량이 10인 비어있는 ArrayList 객체를 생성
            - E: String, Bus 등 저장할 객체의 타입을 명시
        - `ArrayList<E>(int initialCapacity)`: 지정한 initialCapacity 용량을 가진 비어있는 ArrayList 객체를 생성
    - 주요 메소드
        - `boolean add(E e)`: 리스트의 가장 끝 자리에 요소 e를 순서대로 삽입하고 성공 여부를 반환
        - `E get(int index)`: 리스트의 지정한 index 번호에 위치한 요소를 반환
        - `int size()`: 리스트에 현재 저장되어 축적된 총 데이터의 개수를 반환
        - `E remove(int index)`: 지정한 index 위치에 들어있는 데이터를 삭제하고, 삭제된 그 데이터를 반환
