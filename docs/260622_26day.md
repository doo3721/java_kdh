## 1~6교시: 자료구조

- 자료구조 (Data Structure)
    - 데이터를 효율적으로 저장, 조직, 관리하기 위한 논리적인 구조나 보관 방식을 의미함
    - 자바의 컬렉션 프레임워크는 이러한 자료구조를 표준화된 인터페이스로 구현하여 제공함
- 대표적인 자료구조
    - List
        - 순서가 있으며 데이터의 중복 저장을 허용하는 선형 자료구조
        - ArrayList, LinkedList 등
    - Set
        - 데이터의 저장 순서를 보장하지 않으며 중복 저장을 허용하지 않는 자료구조
        - HashSet, TreeSet 등
    - Map
        - 키(key)와 값(Value)의 쌍으로 데이터를 저장하는 자료구조
        - 키는 중복될 수 없으나 값은 중복을 허용
        - 동일한 키로 중복 저장할 경우 마지막에 저장된 자료로 덮어씌움
        - HashMap, TreeMap 등
    - Stack
        - 후입선출 (LIFO, Last In First Out) 구조를 갖는 자료구조
        - 마지막에 들어온 데이터가 먼저 나감
    - Queue
        - 선입선출 (FIFO, First In First Out) 구조를 갖는 자료구조
        - 먼저 들어온 데이터가 먼저 나감
