## 4교시: break, continue

- break
    - 실행되는 순간 실행하는 switch 문이나 반복문을 종료하고 탈출
- continue
    - 해당 실행을 중단하고 다음 실행으로 넘어감

## 의문점

- 100번 도는 for문에 3줄의 명령문 vs (100번 도는 for문의 1줄의 명령문 + 50번 도는 for문의 1줄의 명령문 * 2)
    - 명령을 출력으로 치환하면, 후자가 더 성능면에서 좋아보이는데?
- “String concatenation '+' in loop”는 무엇인가
    - java의 String 객체는 불변 객체, 객체 생성 후 내부 값이 변경되지 않는다
    - 따라서 문자열을 연결 한다면, 값이 바뀌는 대신 새로운 값이 메모리에 할당된다
    - 문자열 연결이 반복된다면, 메모리 이슈가 생길수 있다.
    - 이에 대한 해결: StringBuilder 클래스
