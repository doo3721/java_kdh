## 1교시: 자바스크립트

- 자바스크립트
    - HTML 문서내에 코드를 직접 작성하고 마크업과의 상호 작용을 통해 웹 페이지의 동작을 향상시키기 위해 만들어진 프로그래밍 언어
    - 웹 브라우저에 내장된 자바스크립트 엔진에 의해서 실행되는 인터프리터 방식의 언어
    - C 계열 언어(C-family Languages, C, C++, C#, Java, JavaScript 등) 중 하나로 C, Java와 비슷한 문법
    - 자바스크립트로 할 수 있는 일
        - 유효성 검증
            - 사용자의 폼 입력 데이터 유효성 검증
            - 필수 입력사항 확인
            - 데이터 형식(문자, 숫자, 이메일 등)
        - 이벤트 처리
            - 클릭, 마이수 이동, 키보드 입력 사용자가 브라우저 내에서 발생시키는 이벤트에 대한 처리

## 2교시: 자바스크립트 작성, 변수, 리터럴

- 자바스크립트 코드의 위치
    - 인라인으로 작성
        - HTML 문서내에 `<script>` 태그를 이용하여 코드를 직접 작성
    - 외부 파일로 작성
        - js 확장자를 가진 파일 작성 후 `<script>` 태그에 src 속성으로 지정
- 명령문
    - 자바스크립트는 명령문의 집합으로 구성되며 인터프리터가 명령문을 순차적으로 해석하여 실행
    - 명령문은 줄바꿈이나 세미콜론( ; )으로 구분
- 주석
    - 주석은 코드의 실행에는 영향을 주지 않지만, 코드를 이해하기 쉽게 만들어주는 설명문
    - 개발자가 코드의 목적이나 동작을 설명하거나, 임시로 코드를 비활성화 할 때 사용
    - 한 줄 주석
        - `//` 로 지정, 뒤의 모든 문자가 주석 처리
    - 블럭 주석
        - `/*` 로 시작하고 `*/`로 종료, 시작과 종료 사이의 모든 문자가 주석처리
        - 여러줄에 걸쳐서 적용 가능
- 변수
    - var
        - `var 변수명;`: 전통적인 변수 선언
        - `var 변수명 = 초기값;`: 변수 선언과 동시에 초기화
    - let
        - `let 변수명;`: 블록 스코프 변수 선언
        - `let 변수명 = 초기값;`: 블록 스코프 변수 선언과 동시에 초기화
    - const
        - `const 변수명 = 초기값;`: 상수(constant, 재할당 불가) 선언과 동시에 초기화 (초기값 필수)
- 리터럴
    - 프로그램 소스코드에 직접 입력된 고정된 값
    - 숫자 리터럴
        - 정수: `10`
        - 실수: `3.14`
        - 지수 표기법: `1e3`
    - 문자 리터럴
        - 작은 따옴표: `'Hello'`
        - 큰 따옴표: `"JavaScript"`
        - 템플릿 리터럴: ``Hello ${ js } World``
    - 논리 리터럴
        - 참: `true`
        - 거짓: `false`
    - 배열 리터럴
        - `[ 10, 20, 30 ]`
    - 객체 리터럴
        - `{ name: '나무', age: 9 }`
    - null 리터럴
        - `null`
    - undefined 리터럴
        - `undefined`

## 3교시: 데이터 타입, 연산자

- 강형 언어, 약형 언어
    - 강형(strongly typed) 언어
        - 변수 선언시 데이터 타입을 지정하는 언어 (C, C++, Java 등)
    - 약형(weakly typed) 언어
        - 변수 선언시 데이터 타입을 지정하지 않는 언어 (JavaScript, Python 등)
        - 값에 따라서 자동으로 데이터 타입이 결정됨 (동적 타입, dynamic typed)
- 원시 타입
    - 프로그래밍에서 더 이상 쪼갤수 없는 가장 기본 단위의 데이터 타입을 의미
    - 변수에 값을 직접 저장
    - number: 숫자
        - 64비트 부동소수점 방식
        - 정수, 실수, 음수, 양수 구별 없음
    - string: 문자
        - 큰 따옴표나 작은 따옴표 안에 기술
        - 이스케이프 문자: 문자열 안에서 줄바꿈이나 탭 같은 제어 기능을 수행하거나, 따옴표와 같이 문자열의 시작과 끝을 나타내는 특수 문자를 직접 출력하기 위해 백슬래시( \ ) 뒤에 한 문자를 결합하여 사용하는 문자 조합
            - `\n`: 줄바꿈 (개행)
            - `\t`: 수평 탭
            - `\'`: 작은따옴표
            - `\"`: 큰따옴표
            - `\\`: 백슬래시 자체
    - boolean: 논리값
        - true 또는 false 둘 중 하나의 값을 가지는 데이터
    - undefined: 값이 정의되지 않음
        - 선언만 되고 값이 할당되지 않은 변수에는 타입과 값 모두 undefined로 지정됨
    - null: 값이 없음을 명시적으로 지정
        - 개발자가 명시적으로 값이 비어있음을 지정
        - 타입은 object가 됨
- 참조 타입
    - 변수에 값을 직접 저장하지 않고 값을 참조하는 주소를 저장
    - 종류
        - object
            - Array
            - Function
            - Date
            - RegExp
            - …
- 연산자
    - 산술 연산자

        ```jsx
        let age1 = 1 + 4; // 5
        let age2 = 1 + 4 * 5; // 21
        let age3 = (1 + 4) * 5; // 25
        let age4 = 9 / 4 ; // 2.25
        let age5 = 9 % 4; // 1 (%, 나머지 연산자)
        let age6 = 2 ** 3; // 8 (** 거듭제곱 연산자)
        let age7 = '나이는 ' + age1 + ' 입니다.'; // 나이는 5 입니다. (+, 결합 연산자)
        ```

    - 대입 연산자
        - 기본 대입 연산자(`=`): 우측 항목을 계산한 후 좌측 항목에 할당
        - 덧셈 후 대입(`+=`): 좌측 항목에 우측 항목을 더한 후 좌측 항목에 할당(누적)
        - 뺄셈 후 대입(`-=`)
        - 곱셈 후 대입(`*=`)
        - 나눗셈 후 대입(`/=`)
        - 나머지 연산 후 대입(`%=`)
        - 거듭제곱 후 대입(`**=`)
    - 증감 연산자
        - `++`, `--`
        - 값을 1 증가 또는 감소
        - 후위형(count++, count--)
            - 현재 값을 먼저 사용한 후 값을 증가 또는 감소
            - 다른 연산자와 함께 사용할 경우 원래 값이 연산에 반영된 후 값이 변경
        - 전위형(++count, --count)
            - 값을 먼저 증가 또는 감소한 후 변경된 값을 사용
            - 다른 연산자와 함께 사용할 경우 증가/감소 값이 바로 반영
    - 비교 연산자
        - 두 항을 비교하여 참이면 true, 거짓이면 false를 반환
        - `>`, `<`, `>=`, `<=`, `==`(동등), `===`(일치), `!=`, `!==`
    - 일치 연산자 (===, identical)
        - 두 데이터의 타입과 값을 모두 비교해서 값이 같아도 타입이 다르면 false
        - 일치 연산자 비교 규칙
            - 타입이 다르면 false를 반환하고 타입이 같을 경우 다음 규칙을 따름
                - 숫자이고 같은 값이면 true

                    ```jsx
                    10 === 10 // true
                    0 === 0 // true
                    ```

                - 문자열일 경우 같은 위치에 같은 문자가 있고 대소문자까지 일치하면 true

                    ```jsx
                    'hello' === 'hello' // true
                    'hello' === 'Hello' // false
                    ```

                - boolean일 경우 모두 true이거나 모두 false이면 true

                    ```jsx
                    true === true // true
                    false === false // true
                    ```

                - 모두 null이거나 모두 undefined일 경우 true, null과 undefined는 false

                    ```jsx
                    null === null // true
                    undefined === undefined // true
                    null === undefined // false
                    ```

                - 같은 객체를 참조할 경우 true, 속성이 모두 같은 객체라도 참조 주소가 다른 경우 false

                    ```jsx
                    [10, 20] === [10, 20] // false
                    ```

    - 동등 연산자 (==, equal)
        - 두 데이터의 타입이 다르면 적절히 형변환 후 일치 연산(===)
        - 타입이 달라도 값이 같으면 true
        - 동등 연산자 비교 규칙
            - 타입이 같은 경우 두 값이 일치하다면 true
            - 두 값의 타입이 다를 경우
                - null과 undefined는 true

                    ```jsx
                    null == undefined // true
                    ```

                - 한 값이 숫자이고 다른 하나가 문자열이면, 문자열을 숫자로 변환한 후 비교

                    ```jsx
                    10 == '10' -> 10 === 10 // true
                    ```

                - true는 1로 false는 0으로 변환한 후 비교

                    ```java
                    '1' == true -> 1 == true -> 1 === 1 // true
                    ```

    - 논리 연산자
        - `||` (OR, 논리합)
            - JavaScript에서는 기존 OR 논리 연산과는 다르게 작동한다
                - 앞의 값이 true면 앞의 값을 반환
                - 앞의 값이 false면 뒤의 값을 반환

            ```jsx
               true || false    --> true
              false || true     --> true
            'hello' || 'world'  --> 'hello'
                 '' || 'world'  --> 'world'
                100 || 200      --> 100
                  0 || 200      --> 200
            ```

        - `&&` (AND, 논리곱)
            - JavaScript에서는 기존 AND 논리 연산과는 다르게 작동한다
                - 앞의 값이 true면 뒤의 값을 반환
                - 앞의 값이 false면 앞의 값을 반환
        - `!` (NOT, 부정)
            - 참이면 거짓, 거짓이면 참 반환
        - 데이터 타입별로 truthy/falsy 값이 되는 기준
            - falsy
                - boolean: false
                - number: 0, NaN(Not a Number)
                - string: ''
                - null
                - undefined
            - truthy: falsy 이외의 값
    - 삼항 연산자
        - 조건에 따라 값을 선택하는 연산자
        - `조건 ? 참일 때의 값 : 거짓일 때의 값;`

## 4교시: 조건문

- if 문
    - 지정한 조건식이 참(truthy)일 경우 해당 구문 수행
- if ~ else
    - 지정한 조건식이 참일 경우 거짓일 경우 각각 해당 구문 수행
- if ~ else if
    - 지정한 조건식이 true일 경우 해당 구문을 수행하고 false일 경우 else if 문의 조건식을 순차적으로 비교하여 true에 해당하는 구문을 수행
- switch
    - switch에 지정한 비교값과 매칭되는(===) case 구문 수행
    - 일치하는 case가 없을 경우 default 구문 수행
    - break 구문을 만날 때까지 또는 마지막 case나 default 구문까지 실행

## 5교시: 반복문, 객체(Object), JSON

- while 문
    - 지정한 조건식이 참일 경우 조건이 거짓이 될 때까지 해당 블럭을 반복하여 수행
- do…while 문
    - 코드 블럭을 먼저 실행한 후 지정한 조건식이 참일 경우 조건이 거짓이 될 때까지 해당 블럭을 반복하여 수행
    - 코드가 최소 한번은 실행되어야 할 때 사용
- for 문
    - 지정한 횟수만큼 반복적인 작업을 할 경우 사용
- break
    - 반복문이나 switch문을 즉시 종료
    - break를 감싸고 있는 반복문이나 switch문의 코드 블럭( { } )을 빠져나옴
- continue
    - 반복문 내에서 남아있는 코드를 건너뛰고 다음 반복으로 실행이 넘어감
- Object
    - key-value 쌍의 데이터 집합 (속성, property)
    - 속성의 값으로 모든 데이터 타입 지정 가능
        - 속성의 값으로 함수가 지정된 경우 메소드(method)라 부름
    - 하나의 객체는 여러개의 속성과 메소드를 포함할 수 있음
    - 객체의 속성과 메소드에 접근할 때는 dot 표기법( . )을 사용하거나 대괄호 표기법( [’속성명’] )을 사용

    ```jsx
    // 하나의 객체 정의
    let score = new Object();
    score.kor = 100;
    score.eng = 80;
    score['math'] = 90;
    score.sum = score['kor'] + score.eng + score.math;
    
    console.log('총점', score.sum); // 총점 270
    
    score.eng += 10;
    score.sum = score.kor + score.eng + score.math;
    console.log('수정된 총점', score.sum); // 수정된 총점 280
    ```

    - 객체 생성 방법 - Object 생성자 함수
        - `new Object()`: Object 생성자 함수로 빈 객체를 생성한 후 속성과 메소드를 추가
    - 객체 생성 방법 - 객체 리터럴
        - 객체 생성과 속성, 메소드를 같이 지정

        ```jsx
        var user = {
          name: 'namu',
          age: 9,
          job: 'eat',
          married: false
        };
        
        console.log(user['name'], user.age, user.job, user['married']); // namu 9 eat false
        console.log(typeof user, user); // object { name: 'namu', age: 9, job: 'eat', married: false }
        ```

- JSON(JavaScript Object Notation) 표기법
    - 자바스크립트의 객체와 배열을 표기하기 위한 리터럴
    - 객체는 대부분의 언어가 object, record, struct, dictionary, hash table, map, 연상배열 등으로 구현
    - 배열은 대부분의 언어가 array, vector, list, sequence 등으로 구현
    - 소프트웨어의 설정값이나 네트워크 통신에서 교환하는 데이터의 포맷으로 널리 사용
    - 객체 표기법
        - `{ "속성명1": 속성값1, "속성명2": 속성값2, ... }`
    - 배열 표기법
        - `[ 요소값1, 요소값2, 요소값3, ... ]`
    - value에 지정할 수 있는 데이터 타입
        - string, number, object, array, true, false, null

## 6교시: 배열

- 배열
    - 하나의 변수에 여러개의 값을 지정하는 데이터 구조
    - 순서정보(index)를 이용하여 각 요소를 참조 (0부터 시작)
    - 배열 생성
        - Array 생성자 함수
            - `const score = new Array();`
        - 배열 리터럴 이용
            - `const score = [];`
    - 배열 초기화
        - Array 생성자 함수로 생성 및 초기화
            - `const score = new Array(90, 70, 80);`
        - 배열 리터럴로 생성 및 초기화
            - `const score = [ 90, 70, 80 ];`
    - 배열에 요소 추가
        - index 이용
            - `score[3] = 86;`
        - 배열 메소드 이용
            - `score.push(59);`
    - 배열의 요소 읽기
        - index 이용

            ```jsx
            const score4 = score[3];
            console.log(score4); // 86
            ```

        - 배열 메소드 이용

            ```jsx
            const score5 = score.pop();
            console.log(score5); // 59
            ```

    - 배열의 요소의 수
        - length 이용
    - 배열의 모든 요소 접근
        - for문 이용
        - for…of문 이용

            ```jsx
            for (let elem of arr) {
              // 90
              // 70
              // 80
              // 86
              console.log(elem);
            }
            ```
