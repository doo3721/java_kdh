## 2~3교시: 배열

- 같은 타입의 데이터 여러 개를 하나로 묶어서 순차적으로 관리하는 자료구조
- index(순서정보)를 이용하여 배열의 각 요소를 참조
- 배열의 핵심 특징:
    - 같은 타입만 저장 가능: 서로 다른 타입의 데이터를 혼합해서 저장 할 수 없음
    - 고정된 크기: 선언 및 생성할 때 크기를 지정, 한 번 생성된 배열의 크기는 절대 변경할 수 없음
    - 연속된 메모리 공간: 배열의 요소들은 메모리상에서 물리적으로 연속되게 배치, 빠른 index 접근이 가능
    - 참조 타입: 배열 자체는 객체, 힙(Heap) 영역에 생성, 배열 변수는 해당 객체의 주소값을 가짐
- 배열 생성 시 데이터 타입별 자동 초기화 기본값:
    - byte, short, int, long: 0
    - float, double: 0.0;
    - char: ‘\u0000’ (공백 문자)
    - boolean: false
    - 참조 타입(String, 클래스 등): null
- 배열의 길이
    - 배열에 저장할 수 있는 전체 요소의 개수
    - 읽기 전용 필드인 length를 사용해 가져올 수 있음
- index
    - 각 요소에 접근하기 위해 주어지는 방 번호(순서)
    - 0 ~ (배열 길이 - 1)까지의 범위를 가짐
    - 범위를 벗어난 index로 배열에 접근을 시도하면 ArrayIndexOutOfBoundsException이 발생

## 4~6교시: 배열과 메모리 구조

- Stack 영역
    - 메소드 호출 시 생성되는 로컬 변수들이 적재되는 영역
    - 기본 타입 변수는 실제 데이터 값을 stack에 가지고 있음
    - 참조 타입 변수는 실제 객체가 저장되어 있는 heap 영역의 주소값을 저장함
- Heap 영역
    - new 연산자로 생성된 모든 인스턴스와 배열 객체가 할당되는 영역
        - new 연산자로 생성 → 동적 할당되는 객체
    - 가비지 컬렉터(GC)가 참조 관계가 끊어진 객체들을 감지하여 자동으로 수거
