## 1교시: 복습, 다차원 배열

- 다차원 배열
  - 배열의 요소로 또 다른 배열을 가지는 구조
  - 행과 열로 이루어진 표, 행렬 구조와 유사함
  - 배열이 중첩된 깊이(차수)에 따라서 n차원 배열이라고 부름
  - 행마다 열의 길이를 다르게 지정 가능

      ```java
      int[][] ragged = new int[3][];
      ragged[0] = new int[2]; // 0행은 열 크기가 2
      ragged[1] = new int[4]; // 1행은 열 크기가 4
      ragged[2] = new int[3]; // 2행은 열 크기가 3/
      ```

      ```
           │      │        │
           │      │        │       [0]    [1]
           │      │        │    ┌──────┬──────┐
           │      │    ┌───┼──► │ 0x23 │ 0x37 │
           │      │    │   │    └──────┴──────┘
           │      │    │   │       │      │
           │      │    │   │       │      └─────────────┐
           │      │    │   │       ▼                    ▼
           │      │    │   │    ┌─────┬─────┬─────┐   ┌─────┬─────┬─────┐
           │      │    │   │    │  1  │  2  │  3  │   │  4  │  5  │  6  │
           ├──────┤    │   │    └─────┴─────┴─────┘   └─────┴─────┴─────┘
       arr │ 0x12 │────┘   │      [0]   [1]   [2]       [0]   [1]   [2]
           └──────┘        └────────────────────────────────────────────────
             Stack                            Heap
      ```


## 2교시: 향상된 for문

- 향상된 for문
  - 배열이나 컬렉션의 모든 요소를 처음부터 끝까지 순회할 때, 인덱스없이 편리하게 사용하는 문법
    - 컬렉션: 자바가 제공하는 표준 자료구조 모음(List, Set 등)
  - 인덱스를 직접 제어하지 않으므로 인덱스 범위를 초과하는 에러를 방지
  - 코드가 직관적이고 간결해짐
  - 단, 값을 조회하는 용도로만 가능, 배열의 요소를 직접 수정할 수 없음 (읽기 전용)

      ```java
      int[] scores = {90, 85, 95};
      
      for (int score : scores) {
          System.out.println("점수: " + score);
      }
      ```


## 3~6교시: 배열의 복사

- 배열은 한 번 크기가 결정되면 늘리거나 줄일 수 없다
- 더 많은 저장 공간이 필요할 경우, 새로운 배열을 생성하여 기존 값들을 복사해야함.
- 얕은 복사(Shallow Copy)
  - 배열 변수의 주소값만 복사, 두 참조 변수가 동일한 배열 객체를 가리킴
  - 한쪽에서 값을 수정하면 다른 쪽도 영향을 받음

      ```
               │       │            │
               ├───────┤            │    ┌──────┬──────┬──────┐
       shallow │ 0x50  │────┐    ┌──┼──► │  99  │  20  │  30  │
               ├───────┤    ├────┘  │    └──────┴──────┴──────┘
      original │ 0x50  │────┘       │       [0]    [1]    [2]
               └───────┘            └────────────────────────────
                 Stack                              Heap
      ```

- 깊은 복사 (Deep Copy)
  - 새 배열을 생성한 뒤 기존 배열의 데이터를 복사하는 방식
  - 한쪽에서 값을 수정해도 다른 쪽은 영향을 받지 않음

      ```
               │       │            │
               │       │            │    ┌──────┬──────┬──────┐
               │       │   ┌────────┼──► │  99  │  20  │  30  │
               │       │   │        │    └──────┴──────┴──────┘
               │       │   │        │       [0]    [1]    [2]
               │       │   │        │
               ├───────┤   │        │    ┌──────┬──────┬──────┐
        target │ 0x75  │───┘   ┌────┼──► │  10  │  20  │  30  │
               ├───────┤       │    │    └──────┴──────┴──────┘
      original │ 0x50  │───────┘    │       [0]    [1]    [2]
               └───────┘            └────────────────────────────
                 Stack                               Heap
      ```

- 수동 복사
  - 반복문을 사용하여 원본 배열의 요소를 하나씩 대상 배열로 복사

      ```java
      for (int i = 0; i < original.length; i++) {
        target[i] = original[i];
      }
      ```

- System.arraycopy()
  - JVM 레벨에서 메모리를 직접 복사하여 고속으로 배열 복사를 수행하는 메소드
  - 이미 생성되어 있는 대상 배열에 덮어쓰고 싶을 때 사용
  - 복사할 위치와 붙여 넣을 위치를 자유롭게 조절 가능
  - JVM 레벨에서 직접 고속 메모리 복사를 처리, 성능 극대화가 필요할 때 사용

    ```java
    System.arraycopy(Object src, int srcPos, Object dest, int destPos, int length);
    ```

  - src: 원본 배열
  - srcPos: 원본 배열에서 복사를 시작할 index
  - dest: 대상 배열
  - destPos: 대상 배열에서 복사가 시작될 index
  - length: 복사할 요소의 개수
- Arrays.copyOf()
  - java.util.Arrays 클래스가 제공하는 헬퍼 메소드
  - 새로운 배열 생성과 복사를 한번에 처리
  - 배열 전체를 복사 또는 배열 크기 확장을 하고 싶을 때 사용
  - 내부적으로 System.arraycopy를 감싸서 제공되는 메소드

    ```java
    int[] target = Arrays.copyOf(src, length);
    ```

  - src: 원본 배열
  - length: 생성할 배열의 길이
