## 1~2교시: 복습

## 3~4교시: 멀티 스레드, Thread 클래스

- 멀티 스레드 다중 접속 서버
    - 단일 스레드 접속 처리 서버의 한계
        - 서버 소켓이 1명의 클라이언트 연결을 수령하여 I/O를 수행 중인 경우, 다른 클라이언트들의 연결은 대기열에 계속 블로킹되어 서비스 불능 상태에 도달
            - Socket의 accept(), InputStream의 read() 메소드가 블로킹 메소드이기 때문에 accept()를 실행해서 클라이언트 접속을 대기하거나 read() 메소드를 실행해서 클라이언트의 메세지를 대기하는 상황이 발생
    - 멀티 스레드를 이용한 다중화 구조
        - 클라이언트가 accept()를 통과하여 연결을 생성하면, 즉시 새 실행 스레드를 생성하여 개별 소켓 통신을 이관하고 메인 스레드는 다시 accept 대기로 복귀하여 다중 접속 분산 처리 달성
- 프로세스 (Process)
    - 운영체제로부터 독립적인 메모리 및 필요한 자원을 할당받아 컴퓨터 실행 컨텍스트에 등록되어 구동 중인 단일 프로그램을 의미
- 스레드 (Thread)
    - 하나의 프로세스 내부에서 실행 흐름의 가장 작고 기초적인 단위를 뜻함
    - 메모리 중 스레드마다 독립적으로 가지는 Stack 영역을 제외하고 아래의 JVM 런타임 메모리 영역을 공유하여 협력함
        - 메소드 영역 (Method Area, 클래스/정적 영역): JVM이 구동될 때 생성되며 클래스의 구조 정보, 메소드의 바이트코드 명령어, 정적(static) 변수 등이 저장되어 모든 스레드가 공유함 (OS 프로세스의 Code 및 Data 영역에 대응
        - Heap 영역: 동적으로 할당되는 객체(new 인스턴스)배열이 저장되는 공간으로, 여러 스레드가 해당 객체의 참조 주소를 공유하여 함께 사용할 수 있음
        - Stack 영역 (공유 제외): 메소드 호출 시 사용되는 지역변수, 매개변수, 리턴 주소 등이 저장되는 스레드별 독립적인 공간으로, 각 스레드는 서로 간섭할 수 없는 독립적인 실행 흐름을 가짐
    - 싱글 스레드 (Single-Thread)
        - 프로세스 내부에서 단 하나의 스레드만 생성되어 모든 작업을 하나의 스레드가 순차적으로 처리하는 방식
        - 장점: 구조가 단순하고 공유 자원 경쟁에 따른 오류가 발생하지 않음
        - 단점: 네트워크 요청 대기나 파일 입출력 처럼 오래 걸리는 작업(블로킹)이 발생 할 경우 그 뒤의 모든 코드가 대기 상태에 걸려 프로그램의 반응성이 저하됨
    - 멀티 스레드 (Multi-Thread)
        - 하나의 프로세스 내부에서 동시에 여러 개의 스레드를 생성하여 다중 작업을 병렬적으로 동시 처리하는 방식
        - 장점: 대용량 데이터 처리 속도를 높이고 백그라운드 작업을 분리해 프로그램의 반응성을 극대화
        - 단점: 메모리 공간(heap 등)을 공유하므로 동기화 제어가 부적절할 시 데이터 오염이나 교착 상태(데드락) 문제를 야기할 수 있어 세밀한 설계가 요구됨
- Thread 클래스
    - java.lang 패키지에 소속된 클래스
    - 자바에서 스레드를 생성하고 제어하기 위한 핵심 클래스
    - 스레드로 동작시키고 싶은 클래스는 Thread 클래스를 상속받아 run() 메소드를 오버라이딩해서 구현
    - 생성자
        - `Thread()`: 기본 생성자. 스레드 이름이 자동으로 부여됨 (예: Thread-0, Thread-1)
        - `Thread(String name)`: 스레드의 이름을 직접 지정하여 생성함. 디버깅이나 로그 추적 시 식별에 유용함
        - `Thread(Runnable target)`: 실행할 작업이 정의된 Runnable 구현 객체를 전달받아 스레드를 생성함
        - `Thread(Runnable target, String name)`: Runnable 구현 객체와 스레드 이름을 함께 지정하여 생성함
    - 주요 메소드
        - `void start()`
            - 스레드를 시작함
            - 내부적으로 새로운 호출 스택(Call Stack)을 생성한 뒤 run() 메서드를 자동으로 호출함
            - 직접 run()을 호출하면 새로운 스레드가 생성되지 않고 현재 스레드에서 일반 메서드처럼 순차 실행되므로 반드시 start()를 사용해야 함
        - `void run()`
            - 스레드가 실행할 작업 내용을 정의하는 메서드
            - Thread를 상속한 경우 이 메서드를 오버라이딩하여 실행 코드를 작성함
        - `static void sleep(long millis)`
            - 현재 실행 중인 스레드를 지정한 밀리초(1/1000초) 동안 일시 정지시킴
            - InterruptedException 예외 처리가 필요함
- Thread 생성과 실행
    - Thread 클래스 직접 상속 방식
        - Thread 클래스를 부모로 삼아 run() 메소드를 오버라이딩하여 스레드가 실행할 코드를 명시함
        - 자바는 단일 상속만 지원하므로 다른 클래스를 상속받아야 하는 경우 다중 상속 제약이 발생

        ```java
        class MyThread extends Thread {
            @Override
            public void run() {
                System.out.println("Thread 상속 기반 동작");
            }
        }
        
        // 스레드 객체 생성 및 실행
        new MyThread().start();
        ```

    - Runnable 인터페이스 구현 방식 (권장)
        - Runnable 인터페이스의 run() 추상 메소드를 구현하여 실행할 작업을 정의
        - 인터페이스를 구현했으므로 다른 클래스 상속에 제한이 없고 실행 스레드와 작업 태스크 단위를 독립적으로 분리할 수 있어 결합도가 낮은 구조 설계가 가능함

        ```java
        class MyRunnable implements Runnable {
            @Override
            public void run() {
                System.out.println("Runnable 인터페이스 구현 기반 동작");
            }
        }
        
        // Thread 객체 생성 시 Runnable 구현체를 전달하여 시작
        new Thread(new MyRunnable()).start();
        ```


## 5~6교시: 익명 클래스

- 익명 클래스
    - 클래스의 선언과 동시에 객체(인스턴스) 생성을 한 번에 처리하는 이름이 없는 일회성 클래스
    - 주로 특정 부모 클래스를 상속받거나 인터페이스를 구현한 후 내부에 선언된 추상 메소드를 일회용으로 즉석에서 구현해 사용할 때 활용
    - 익명 클래스를 만드는 방법
        - 별도의 클래스를 만들지 않고 new 연산자 뒤에 대상이 될 부모 클래스 이름 또는 인터페이스 이름을 지정한 뒤 곧바로 중괄호 { } 를 붙여 추상 메소드의 본문을 완전히 즉석에서 완성해 주면 자바 컴파일러는 이를 이름 없는 임시 구현 클래스로 인식하여 정상적인 객체 생성을 허용함

        ```java
        new 부모클래스_또는_인터페이스() {
            // 추상 메서드 재정의
        };
        ```

        - 원래 자바에서 인터페이스는 자체적으로 객체를 생성할 수 없지만, 이처럼 `new 인터페이스명()` 뒤에 중괄호 {} 를 붙여 추상 메소드의 본문을 완전히 즉석에서 완성해 주면 자바 컴파일러는 이를 이름 없는 임시 구현 클래스로 인식하여 정상적인 객체 생성을 허용함

        ```java
        // 1. 일반적인 구현 방식 (이름 있는 클래스 정의)
        class Task implements Runnable {
            @Override
            public void run() {
                System.out.println("일반 클래스 기반 동작");
            }
        }
        new Thread(new Task()).start();
        
        // 2. 익명 클래스(Anonymous Class) 구현 방식
        new Thread(new Runnable() {
            @Override
            public void run() {
                System.out.println("익명 클래스 기반 동작");
            }
        }).start();
        ```
