## 2~3교시: 조건문 if

- 조건문
    - 조건식이 참 또는 거짓일 때 특정한 블록을 실행하는 프로그래밍 문법
- if 문
    - if: 조건식이 참 일 때만 지정한 블록을 실행
    - if-else: 조건식이 참 일 경우 if 블록, 거짓일 경우 else 블록을 실행
    - if-else if: 조건식이 참 일 경우 if 블록, 거짓일 경우 else if의 조건식을 순차적으로 비교하여 참에 해당하는 블록을 실행
    - 중괄호 생략 규칙
        - if, else, else if 블록 내에 실행할 구문이 한 줄일 경우, 중괄호를 생략 가능
        - 단, 가독성이 떨어질 수 있고, 버그가 생기기 쉬우므로 실무에서는 가급적 중괄호를 작성하는 것을 권장

## 4-6교시: 조건문 switch

- switch 문
    - switch 구문의 비교값과 같은 case 블록을 찾아서 실행
    - break 키워드를 만날때까지 아래에 위치한 case 블록을 순차적으로 실행
- 새롭게 추가된 switch 문 (Switch Expression)
    - 자바 12 버전부터 도입, 14부터 표준화
    - 기존 콜론(:)과 break 키워드를 사용하는 방식 대신 화살표 연산자(->)를 활용하여 가독성을 높이고 실수를 방지
    - 기존 switch 문이 실행만을 목적으로 하는 제어문이었다면, 새로운 switch문은 그 자체로 최종 결과를 직접 반환할 수 있는 식(Expression)으로 동작
- Switch Expression 특징
    - break 키워드 불필요: case에 해당하는 명령문만 실행하고 switch 문을 빠져나감
    - 다중 조건 결합: 쉼표(,)를 사용하여 여러 case 조건을 한 줄에 간결하게 선언
    - 값의 직접 반환: switch 식 자체를 변수의 대입 연산 우측에 배치하여 값을 직접 반환 할 수 있음
    - yield 키워드: 복잡한 명령 처리를 위해 중괄호’{}’ 구성할 경우, 블록 내부에서 yield 키워드를 사용하여 결과값을 외부로 반환 할 수 있음
    - 화살표 연산자 사용시 기존 switch와 혼용할 수 없다
