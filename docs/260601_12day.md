## 3~6교시: 객체지향 프로그래밍 (Object-Oriented Programming)

- 컴퓨터 프로그램을 단순한 명령어의 나열로 보지 않고, 독립된 단위인 객체들이 모여서 서로 메세지를 주고받으며 협력하는 형태로 작성하는 프로그래밍 패러다임
- 핵심 지향점
  - 프로그램의 부품화
    - 데이터와 이를 처리하는 메소드를 객체라는 하나의 부품으로 결합, 구조화
  - 재사용성과 유지보수성
    - 완성도 높은 객체를 만들어 여러 곳에서 다시 사용, 변경 사항이 생겼을 때 해당 객체만 수정
- 객체 (Object)
  - 우리가 인지하고 표현하려는 유무형의 모든 실체
  - 고유한 속성(상태)과 행위(동작)를 가짐
- 클래스 (Class)
  - 객체를 생성하기 위한 설계도
  - 객체의 형태와 기능을 코드로 사전에 명세해 둔 규격
  - 메모리에 실체는 없음
- 인스턴스 (Instance)
  - 클래스라는 설계도를 바탕으로 ‘new’ 연산자를 사용하여 힙 메모리에 실제로 만들어진 실체화된 결과물 (객체)
- 클래스의 구성 요소
  - 필드 (Field): 객체의 상태, 속성을 정의한 변수
  - 메소드 (Method): 객체의 동작, 행위, 기능
  - 생성자 (Constructor): 객체가 new로 생성될 때 초기 세팅을 담당
- 필드 (Field)
  - 클래스 내부에 선언되어 객체의 상태와 속성을 정의하는 변수, 멤버 변수라고도 함
  - 자동 초기화: 명시적으로 초기화하지 않아도 객체가 생성될 때 각 자료형의 기본값을 자동 초기화
